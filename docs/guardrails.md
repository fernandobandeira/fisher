# Guardrails

| Guardrail | What it stops | Why it matters with agent-written code | Where enforced | When |
|---|---|---|---|---|
| Formatter | Layout drift | Reviews can focus on behavior | [`cargo fmt --all -- --check`](../scripts/check) | Every commit, PR, weekly |
| Compiler and Clippy lints | Discarded results, panic shortcuts, unchecked conversions and catch-all match arms | Errors and new cases need explicit handling | [Workspace lints](../Cargo.toml) via [`scripts/check`](../scripts/check) | Every commit, PR, weekly |
| Forbidden `unsafe` | Code that bypasses Rust's safety checks | The owner can rely on Rust's safety guarantees | [Workspace lint](../Cargo.toml) and [ADR](adr/0001-rust-with-unsafe-forbidden.md) | Every commit, PR, weekly |
| Reasoned lint exceptions | Silent suppression with `#[allow]` | The owner can review the reason and Clippy flags obsolete expectations | [Workspace lints](../Cargo.toml), [AGENTS.md](../AGENTS.md#guards) | Every commit, PR, weekly |
| Crate dependencies | Edges outside the allowed directions | Capabilities keep clear owners | [Boundary table](../scripts/check-crate-boundaries). Fisher → bench, deepening, uci. Bench and deepening → rules, search. Uci → deepening, rules. Search → rules. Rules and xtask have no workspace dependencies. | Every commit, PR, weekly |
| Deep modules | Public implementation modules or alternate library entry paths | Callers use a small, deliberate interface | [`cargo xtask interfaces`](../crates/xtask/src/interfaces.rs), [`lib.rs` path check](../scripts/check-crate-boundaries), [interface rules](../CODING_STANDARDS.md#crate-interfaces) | Every commit, PR, weekly |
| `unreachable_pub` | Unnecessarily public items inside private modules | Internal code stays free to change with its crate | [Workspace lint](../Cargo.toml) | Every commit, PR, weekly |
| Glossary | Banned wording in identifiers | Names mean the same thing across crates | [Glossary](../GLOSSARY.md) and [`cargo xtask glossary`](../crates/xtask/src/glossary.rs) | Every commit, PR, weekly |
| Independent expected values | Tests that attest to the implementer's own output | A separate source can prove a claim wrong | [`expectations/`](../expectations/README.md), [evidence rules](evidence.md) | Tests every commit, PR, weekly. Provenance in review |
| Development-only reference | Shipping the independent chess reference as an engine dependency | The reference can check engine behavior independently of the engine | [`shakmaty` dependency check](../scripts/check-crate-boundaries) | Every commit, PR, weekly |
| Test ownership | Library behavior covered solely by tests in the binary crate | A crate's own test invocation reaches its public interface | [Dependency check](../scripts/check-crate-boundaries), [test placement rule](../CODING_STANDARDS.md#crate-interfaces) | Dependency edges every commit, PR, weekly. Test placement in review |
| Bench signature | A changed fixed-search node count | A refactor has a stable observation the owner can check | [Signature test](../crates/bench/tests/signature.rs), [`fisher bench` and commit record](process.md#recording-the-bench-signature) | Signature test every commit, PR, weekly. Commit record in review |
| Strength record | Unsupported claims about playing strength | The owner can trace an improvement claim to a match | [`strength/measure` and records](../strength/README.md) | When claiming a strength change |
| Dependency advisories and sources | Known vulnerable dependencies and unauthorized sources | Dependencies get checked even in a small implementation change | [`cargo deny`](../scripts/check), [configuration](../deny.toml) | Every commit, PR, weekly |
| Protected paths and `Guard-Change:` | Changes to checking policy without a stated reason | The owner can find and review changes to what passes | [Protected paths](../.githooks/protected-paths), [commit-message hook](../.githooks/commit-msg) | Every commit with the hooks installed |
| Pre-commit hook | Committing after a failed local check | A broken intermediate commit is caught locally | [Pre-commit hook](../.githooks/pre-commit) | Every commit with the hooks installed |
| Claude Code stop hook | Ending a turn with unchecked changes | The agent gets a chance to fix a red check before handing back | [Stop hook](../.claude/hooks/stop-check) | End of a dirty Claude Code turn |
| CI | Missing shared check results | The owner can inspect results from a fresh checkout | [Check workflow](../.github/workflows/check.yml) | Push, PR, weekly |
| Review and tiers | Merging behavior or commitments without the required review | The owner spends attention on claims, interfaces and guards | [Process tiers](process.md#tiers) and [review](process.md#what-the-human-reads-in-order) | Prose only |
| Ticketed TODO | Deferred work with no owner-visible record | A missing behavior stays findable after the agent leaves | [Deferred work rules](../CODING_STANDARDS.md#deferred-work) | Prose only |
| Cognitive complexity | Functions that exceed a complexity of 8 | Important branches stay readable when a defect does need review | [Workspace lint](../Cargo.toml), [threshold](../clippy.toml) | Every commit, PR, weekly |
| Mutation testing | Tests that pass despite a behavior change | A surviving mutant identifies an assertion or proof the owner needs | [`scripts/check-mutants`](../scripts/check-mutants), [reviewed scope and equivalents](../.cargo/mutation-gate.json) | Changed lines on PRs, full scope weekly |
| Per-crate region coverage | Losing coverage in one crate while others stay high | A weakly covered crate cannot hide in a workspace total | [`scripts/check-coverage`](../scripts/check-coverage), [reviewed floors](../.cargo/coverage-floors.json) | PR |
