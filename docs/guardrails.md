# Guardrails

The `main gates` ruleset on `main` requires the GitHub Actions `check`, `mutation`, and `coverage` jobs to pass and the pull request to be up to date with `main`. GitHub blocks red and out-of-date pull requests, force-pushes to `main`, and deletion of `main`. Nobody is on a bypass list. See the [merge process](process.md#pull-requests).

| Guardrail | What it stops | Why it matters with agent-written code | Where enforced | When |
|---|---|---|---|---|
| Formatter | Layout drift | Reviews can focus on behavior | [`cargo fmt --all -- --check`](../scripts/check) | Each commit and CI run |
| Workspace lint inheritance | A crate omitting the workspace lints | New crates start with the same checks | [`scripts/check`](../scripts/check) checks each manifest | Each commit and CI run |
| Compiler and Clippy lints | Discarded results, panic shortcuts, unchecked conversions and catch-all match arms | Errors and new cases need explicit handling | [Workspace lints](../Cargo.toml) via [`scripts/check`](../scripts/check) | Each commit and CI run |
| Forbidden `unsafe` | Code that bypasses Rust's safety checks | The owner can rely on Rust's safety guarantees | [Workspace lint](../Cargo.toml) and [ADR](adr/0001-rust-with-unsafe-forbidden.md) | Each commit and CI run |
| Reasoned lint exceptions | Silent suppression with `#[allow]` | The owner can review the reason and Clippy flags obsolete expectations | [Workspace lints](../Cargo.toml), [AGENTS.md](../AGENTS.md#guards) | Each commit and CI run |
| Crate dependencies | Edges outside the allowed directions | Capabilities keep clear owners | [Boundary table](../scripts/check-crate-boundaries). Fisher → bench, deepening, uci. Bench and deepening → rules, search. Uci → deepening, rules. Search → rules. Rules and xtask have no workspace dependencies. | Each commit and CI run |
| Deep modules | Direct public module declarations at the library root and alternate library entry paths | Callers use a small, deliberate interface | [`cargo xtask interfaces`](../crates/xtask/src/interfaces.rs), [`lib.rs` path check](../scripts/check-crate-boundaries), [interface rules](../CODING_STANDARDS.md#crate-interfaces) | Each commit and CI run. A person reviews macro-generated exports and re-exports |
| `unreachable_pub` | Unnecessarily public items inside private modules | Internal code stays free to change with its crate | [Workspace lint](../Cargo.toml) | Each commit and CI run |
| Glossary | Banned wording in identifiers | Names mean the same thing across crates | [Glossary](../GLOSSARY.md) and [`cargo xtask glossary`](../crates/xtask/src/glossary.rs) | Each commit and CI run |
| Independent expected values | Tests that attest to the implementer's own output | A separate source can prove a claim wrong | [`expectations/`](../expectations/README.md), [evidence rules](evidence.md) | Tests each commit and CI run. Provenance in review |
| Development-only reference | Shipping the independent chess reference as an engine dependency | The reference can check engine behavior independently of the engine | [`shakmaty` dependency check](../scripts/check-crate-boundaries) | Each commit and CI run |
| Test ownership | A caller’s tests supplying the evidence for a crate | Each crate’s unit and integration tests must defend its own code | [Mutation](../scripts/check-mutants) and [coverage](../scripts/check-coverage). The [dependency check](../scripts/check-crate-boundaries) enforces allowed edges | Mutation and coverage on each CI run. Dependencies in `scripts/check` |
| Published perft | Incorrect legal move counts | Published values check the engine independently | [Expected counts](../expectations/perft.epd), [rules](../crates/rules/tests/positions.rs), [search](../crates/search/tests/search.rs) | Shallow in `scripts/check`. Deep perft uses the ignored release-mode tests on request |
| Seeded reference comparison | Differences in legal moves, resulting positions, check detection or search results | Reachable positions exercise cases nobody selected by hand | [Rules comparison](../crates/rules/tests/positions.rs), [search comparison](../crates/search/tests/search.rs) | In `scripts/check`. The complete published mate suite is ignored by default and run in release mode on request |
| UCI transcripts | Incorrect responses, process exits or search reports | The wired binary has to satisfy the GUI contract | [Transcript runner](../crates/fisher/tests/transcripts.rs), [expected transcripts](../expectations/uci) | In `scripts/check` |
| Bench signature | A changed fixed-search node count | A refactor has a stable observation the owner can check | [Signature test](../crates/bench/tests/signature.rs), [`fisher bench` and commit record](process.md#recording-the-bench-signature) | Signature test each commit and CI run. Commit record in review |
| Strength record | Unsupported claims about playing strength | The owner can trace an improvement claim to a match | [`strength/measure` and records](../strength/README.md) | When claiming a strength change |
| Dependency advisories and sources | Known vulnerable dependencies and unauthorized sources | Dependencies get checked even in a small implementation change | [`cargo deny`](../scripts/check), [configuration](../deny.toml) | Each commit and CI run |
| Protected paths and `Guard-Change:` | Changes to checking policy without a stated reason | The owner can find and review changes to what passes | [Protected paths](../.githooks/protected-paths), [commit-message hook](../.githooks/commit-msg) | Every commit with the hooks installed |
| Pre-commit hook | Committing after a failed local check | A broken intermediate commit is caught locally | [Pre-commit hook](../.githooks/pre-commit) | Every commit with the hooks installed |
| Claude Code stop hook | Ending a turn with unchecked changes | The agent gets a chance to fix a red check before handing back | [Stop hook](../.claude/hooks/stop-check) | End of a dirty Claude Code turn |
| CI | Missing shared check results | The owner can inspect results from a fresh checkout | [Check workflow](../.github/workflows/check.yml) | All PRs, pushes to `main`, weekly |
| Review and tiers | Merging behavior or commitments without the required review | The owner spends attention on claims, interfaces and guards | [Process tiers](process.md#tiers) and [review](process.md#what-the-human-reads-in-order) | Prose only |
| Ticketed TODO | Deferred work with no owner-visible record | A missing behavior stays findable after the agent leaves | [Deferred work rules](../CODING_STANDARDS.md#deferred-work) | Prose only |
| Cognitive complexity | Functions that exceed a complexity of 8 | Important branches stay readable when a defect does need review | [Workspace lint](../Cargo.toml), [threshold](../clippy.toml) | Each commit and CI run |
| Mutation testing | A crate’s own tests passing despite a behavior change | A surviving mutant identifies an assertion or proof the owner needs | [`scripts/check-mutants`](../scripts/check-mutants), [reviewed equivalents](../.cargo/mutation-gate.json) | Whole workspace on each CI run |
| Per-crate region coverage | Losing coverage supplied by a crate’s own tests | Each crate has a separate report and floor. Dedicated test-only files are excluded. Source paths escaping `src/` and build scripts fail the layout check | [`scripts/check-coverage`](../scripts/check-coverage), [reviewed floors](../.cargo/coverage-floors.json) | Each CI run |

Coverage floors use the measured regions and half-point rounding. The bench tests exercise a failed position write. The final total write and the final flush can also fail, but testing both would add two complete four-ply benches to `scripts/check`. The fixed perft data also leaves the invalid-FEN path uncovered. The rules constructors require kings and valid square coordinates, leaving defensive paths for a missing king or an out-of-bounds square outside public tests. Deepening’s remaining gap is in its inline test code. UCI’s uncovered regions include error propagation in response and move formatting, reader exit after the receiver disconnects, OS thread-spawn failure, and inline test code. The binary’s own bench and transcript tests cover both paths through `main`, including a failed bench write.

The pull-request mutation job runs the whole workspace. Diff scoping was removed because changes to shared tests, manifests, expected data and the gate itself can affect mutants outside the diff. Reintroduce scoping if the hosted run grows past about 15 minutes.
